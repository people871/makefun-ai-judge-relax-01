A short text for a tired reader: the library door clicks shut behind
the last reader, the chairs are pushed back in, a book lies open under
the one lamp still on — and the night comes on slowly, one page at a
time. No instructions, no wellness slogans: just the room, the sounds,
and the books waiting. `main.py` (Python 3.13, standard library only)
writes the 585-character text to `/output/entry.txt`,
deterministically, on every run.

Run it: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py`
